# 데일리 상차 리포트 앱 시안

## 대표 시안

- `daily-report-app-flow.png`

이 이미지는 현재 확정 방향에 가까운 4화면 시안이다.

1. 홈 화면
2. `1/2 전표 촬영` 카메라 화면
3. `2/2 미상차 촬영` 카메라 화면
4. 전표/미상차 세트 확인 및 기록 저장 화면

## 구현 기준

- 홈에서 `오늘 상차 리포트 시작`으로 작업을 시작한다.
- 전표와 미상차 사진은 한 세트로 묶는다.
- 전표 촬영 후 바로 미상차 촬영 단계로 넘어간다.
- 미상차 사진은 여러 장 추가할 수 있다.
- 세트 완료 후 매장명, 고객코드, 호차, 착순, 문구를 확인한다.
- 기록 저장 후 전체 기록 검색과 CSV 내보내기로 이어진다.
